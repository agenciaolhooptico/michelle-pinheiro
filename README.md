# Michelle Pinheiro Clinic

Site estático comercial, responsivo e em português. Node.js 20 ou superior, sem dependências npm.

## Desenvolvimento

Execute `node scripts/build.mjs` para gerar `docs/` a partir de `src/`. Execute `node scripts/serve.mjs` para abrir a prévia local na porta 8768.

GitHub Pages: branch `main`, pasta `/docs`.

## Direção visual aprovada no briefing

Dourado, off-white e palha. Cantos arredondados, tipografia grande e fades suaves. Procedimentos antes da apresentação da profissional. Banner com a frase “Descubra a sua melhor versão” e o retrato profissional anexado pelo usuário em 29/10/2026. Sem foto de IA, pacientes, embalagens inventadas, depoimentos ou promessas de resultado.
