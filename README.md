# Michelle Pinheiro Clinic

Site estático responsivo, em português, preparado para GitHub Pages.

## Desenvolvimento

Node.js 20 ou superior, sem dependências npm.

```sh
npm run build
npm start
```

Fonte em `src/`. O build copia a versão validada para `docs/`. Configure o GitHub Pages para publicar a branch `main`, pasta `/docs`.
