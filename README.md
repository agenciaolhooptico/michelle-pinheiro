# Michelle Pinheiro Clinic

Site estático responsivo, em português, preparado para GitHub Pages.

## Desenvolvimento

Node.js 20 ou superior, sem dependências npm.

```sh
npm run build
npm start
```

Fonte em `src/`. O build copia a versão validada para `docs/`. Configure o GitHub Pages para publicar a branch `main`, pasta `/docs`.

## Conteúdo e imagens

- Tratamentos e nomes dos produtos foram informados no briefing.
- Não foram incluídos depoimentos, números de resultados, preços, formação, registro profissional ou classificação como dermatologista.
- Agendamento pelo perfil oficial informado: https://www.instagram.com/michellepinheiroclinic/
- Imagem de capa gerada com a ferramenta integrada Imagegen; imagem conceitual, sem representar a profissional, pacientes ou a clínica. Monograma tipográfico e composições dos produtos são criações visuais para esta proposta, sem reprodução de embalagens.
- As artes fornecidas foram usadas somente como referência de direção visual. Não foram republicadas.
- Referência estrutural: site da Dra. Cíntia Kimura, com nova composição, cores e conteúdo para Michelle Pinheiro.
